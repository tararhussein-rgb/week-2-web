
# Personal Budget & Expense Tracker

## Project Overview

The Personal Budget & Expense Tracker is a beginner-friendly web project built using HTML and CSS. It helps demonstrate how expenses can be organized and displayed in a simple table.

This project is part of the Week 2 HTML and CSS assignment.

## Features

- Expense form with name, amount, category, and date fields.
- Category dropdown with Food, Transport, Rent, Entertainment, and Other.
- Expense table with five sample records.
- Alternating table row colors and hover effects.
- Logo image beside the main heading.
- Embedded YouTube video for budgeting tips.
- Collapsible instructions using HTML details and summary.
- Responsive layout for smaller screens.
- Advanced CSS selectors, including focus, hover, nth-child, and not.

## Project Files

### index.html
Contains the webpage structure, expense form, sample expense table, image, video, and instructions.

### style.css
Controls the webpage appearance, including colors, spacing, borders, table styling, input focus effects, and responsive design.

### README.md
Describes the project, its features, and the purpose of each file.

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git and GitHub

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Review the expense form, sample table, help section, and video.

## Current Limitations

The expense form is a visual demonstration. The Add Expense button does not save or add expenses because JavaScript functionality will be introduced in a later week.
